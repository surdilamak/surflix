# Sagas for the Reference "Watch order" timeline.
#
#   @saga <slug> | <Name> | <tip EN> || <tip ID>
#   @lane <id> | <label EN> || <label ID> [| fork: Title (year)]
#   Title (year) | <lane> | <release YYYY-MM or YYYY> | <in-story label, optional> | <note EN || note ID, optional>
#
# The ORDER OF THE LINES is the story order. Release order comes from the release field.
# A lane with `fork:` is drawn as a branch that leaves the line at that title.
# Titles must match the Surflix library exactly ("Title (year)"); a title that is not in the library is
# drawn as a "Not on Surflix" placeholder so the chronology never has a silent hole.
# Leave the release month empty when unsure. Leave the story label empty when unsure.
# Run: node scripts/build-sagas.js  (writes lib/sagas.json and reports titles missing from the library)
